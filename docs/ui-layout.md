# 地面站自适应界面

本次确认的布局：选择列使用居中的单独勾选框，不显示空文本格；增加全选框，反映全选、部分选中、未选中状态。每架飞机自己的局部坐标图同时展示，随可用宽度自动换列，不能误解为共同地图。状态表、航点编辑/地图、日志之间可拖动调整。

实施顺序：
1. 替换选择单元格并连接全选状态，保持批量操作仅针对勾选飞机。
2. 复用 LocalPlot，建立按飞机编号索引的小图网格；未收到数据也显示该机占位图。
3. 移除表格和地图的大固定尺寸，使用分隔条和滚动区；操作按钮窄窗口自动换行，初始窗口适配屏幕可用区域。
4. 离线验证选择与批量操作编号、独立图更新、宽窄窗口布局，检查截图；不修改 SSH、任务状态机或机载程序。

GNSS 补充：保留每机持续状态轮询；经纬度按钮、状态表和添加操作统一检查当前参考与遥测时效，信号恢复后自动启用，超过 3 秒未更新时禁用。米制点不受 GNSS 限制。

验证完成：离线检查全选/部分选中、仅向勾选飞机提交模拟任务、各机图独立更新、窗口缩放，以及 GNSS 失效/恢复/遥测超时，共 5 项通过。检查 1600×1000、1280×800、800×600 的布局；小窗口使用滚动区。interface.png 为离线演示截图。临时测试脚本已清理；未执行真实飞行命令。
