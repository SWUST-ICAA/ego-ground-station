# 地面站实施计划

目标：独立 Git 项目，PyQt5 + Paramiko，复用部署的 ROS1/MAVROS/EGO。

1. onboard/geo.py：WGS84/ECEF/ENU 与单机偏航转换；验证同点、东西南北、90 度旋转、日期变更线、无效值。
2. onboard/mission.py：无 ROS 的状态机；验证无 GNSS 米制执行、地理输入拒绝、稳定起飞/到点/返航/降落、手动接管、过期状态、重复任务、边界和超时。
3. onboard/agent.py：订阅 MAVROS、点云、桥、轨迹，持久任务执行，Unix socket JSON；使用请求 ID 去重，状态更新使用单调时钟；校验机上消息与服务结果。只在新鲜已着陆未解锁时允许停止。
4. ground_station/transport.py：每机独立 SSH 后台工作线程、部署代理、状态轮询、命令序列化；不阻塞 Qt。重连只获取状态，不重发飞行命令。
5. ground_station/ui.py：三机状态、逐机航点增删/保存、批量控制、轨迹、日志；明确无 GPS 可用米制。模拟模式只连接本地模型。
6. main.py / run.sh / README.md：直接启动、凭据配置不跟踪、模拟模式、协议说明和验证边界；完成独立 Git 提交。
7. 验证异常及全部主要流程，清理临时测试，提交源码；真机只启动观测代理并读取，不触发飞行动作。

实施状态：1～7 已完成。源码、使用说明及界面图已纳入独立 Git；三机仅启动观测代理，尚无实机飞行验收。
