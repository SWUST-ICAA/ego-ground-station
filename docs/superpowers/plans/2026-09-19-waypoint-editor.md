# 航点编辑区优化

用户已确认输入表单＋航点列表方案。

目标：加宽编辑区，提供带单位的坐标输入、读取当前位置、添加、修改、删除和上移/下移；点击飞机状态行或地图切换编辑对象。保留七机地图及 GNSS 自动可用性检查。

结构：新增 ground_station/waypoint_editor.py 管理表单与列表，通过信号提交航点；ui.py 负责每机配置保存和遥测；view_widgets.py 提供地图点击信号。机载任务和 SSH 协议保持现有实现。

步骤：
1. 实现表单与列表，坐标范围检查、每机输入草稿和显式保存。
2. 接入飞机选择、GNSS 状态与配置保存，调整编辑区默认宽度。
3. 离线验证添加/修改/排序/删除、飞机隔离、GNSS 恢复、过期位置拒绝，以及宽窄窗口截图。
4. 更新说明，删除临时测试文件，提交 Git。

完成：输入表单、显式保存、各机草稿、地图/状态行切换已实现。离线检查覆盖航点增改删排序、GNSS 恢复/超时、仅勾选飞机提交、日志错误显示、1600×1100 与 800×600 缩放。

追加需求：删除 mission.py 的起飞点局部 z 零点偏差拒绝条件；所有 QMessageBox 改为日志，不再二次确认飞行动作。用 z=-0.8 和 z=0.8 验证该条件已解除，并确认未就绪检查仍有效。未向实机发送命令或重启代理；新版机载代码通过关闭/启动程序加载。
